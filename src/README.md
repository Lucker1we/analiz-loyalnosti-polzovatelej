# Исходный код (Source Files)

В этой папке сосредоточена вся бизнес-логика проекта: загрузка данных, предобработка, расчет продуктовых метрик и анализ.

## 🏗 Архитектура и основные методы

Проект построен на объектно-ориентированном подходе. Основная точка входа (`main.py` в корне) создает экземпляры классов из этой папки.

### Загрузка данных
* `load_data()` — скачивает датасеты заказов и мероприятий из удаленного S3-хранилища (ссылки берутся из `.env`), форматирует даты и возвращает отфильтрованный `pd.DataFrame`, либо скачивает датасеты по ссылке (из `.env`).
* `load_converter_df()` — локально загружает справочник курсов валют (тенге) из папки `data/` для последующей конвертации стоимости билетов.

### Создание пользовательских профилей 
`create_profiles(df)` — создаёт набор пользовательских профилей на основе поступившего датасета
### Аналитика и графики
* `retention_analysis(user_profiles, show_plots=False)` — комплексный метод для маркетингового анализа:
  * Рассчитывает доли вернувшихся пользователей (`is_two`) по типам событий, устройствам и регионам.
  * Выводит таблицы распределения (числовой аналог `countplot`).
  * (Опционально) Строит графики распределения выручки (`sns.histplot`) и тепловую карту Phik-корреляции для сегментов активности.
